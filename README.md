# P.A.N.I.C. — คลังไอเดียโครงงาน

Next.js 14 (App Router) + Tailwind + Supabase
วิธีขึ้นใช้งานจริงอยู่ใน **[DEPLOY.md](./DEPLOY.md)**

## รันครั้งแรก

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 ได้เลย **ยังไม่ต้องตั้งค่า Supabase**
ระบบจะใช้ข้อมูลตัวอย่าง 8 โครงงานใน `lib/data.ts` ไปก่อน
พอใส่ค่าใน `.env.local` แล้ว หน้าเว็บจะสลับไปอ่านจากฐานข้อมูลเองอัตโนมัติ

## หน้าที่มี

| เส้นทาง | ใคร | ทำอะไร |
|---|---|---|
| `/` | ทุกคน | หน้าแรก กิจกรรมที่เปิดรับ โครงงานแนะนำ |
| `/projects` | ทุกคน | คลังโครงงาน กรองตามชั้น หมวด ความยาก งบ |
| `/projects/[slug]` | ทุกคน | รายละเอียด + ปุ่มบันทึก (ต้องล็อกอิน) |
| `/quiz` | ทุกคน | แบบทดสอบ 10 ข้อ + ผลลัพธ์พร้อมเหตุผล |
| `/calendar` | ทุกคน | ปฏิทินกำหนดส่ง |
| `/login` | ทุกคน | เข้าสู่ระบบด้วยลิงก์ทางอีเมล ไม่มีรหัสผ่าน |
| `/me` | ล็อกอิน | โครงงานที่บันทึก ความคืบหน้า กิจกรรมที่ติดตาม |
| `/admin` | แอดมิน | ภาพรวม เพิ่มโครงงาน เพิ่มกิจกรรม คิวตรวจอนุมัติ |

## ระบบแนะนำ 3 ชั้น

1. **กรองด้วย SQL** (`lib/match.ts`) — ระดับชั้น งบ เวลา ไม่ให้แนะนำของที่ทำไม่ได้จริง
2. **ให้คะแนนตามน้ำหนักแท็ก** — จากคำตอบใน `lib/quiz.ts`
3. **ให้ LLM เขียนเหตุผล** (`lib/llm.ts`) — ใส่ `GEMINI_API_KEY` หรือ `TYPHOON_API_KEY`
   ไม่ใส่ก็ทำงานได้ ระบบจะใช้ข้อความสำเร็จรูปแทน และถ้า API ล่มก็ตกกลับมาที่ข้อความสำเร็จรูปเช่นกัน

## โครงสร้าง

```
app/
  page.tsx  projects/  quiz/  calendar/       หน้า public
  login/  auth/  me/                          ระบบผู้ใช้
  admin/                                      หน้าผู้ดูแล + server actions
  api/match/  api/save/                       API
lib/
  quiz.ts        คำถามและน้ำหนักแท็ก  <- แก้คำถามที่นี่ที่เดียว
  match.ts       ระบบแนะนำชั้น 1–2
  llm.ts         ระบบแนะนำชั้น 3
  data.ts        ชั้นดึงข้อมูล (Supabase หรือข้อมูลตัวอย่าง)
db/
  schema.sql     สคีมาเต็ม + RLS + pg_cron
  seed.sql       หมวดหมู่ แท็ก คำถาม กิจกรรม โครงงานตัวอย่าง
```

## ยังไม่ได้ทำ

- ค้นหาด้วยคำ — ต้องตัดคำไทยด้วย PyThaiNLP ลงคอลัมน์ `search_text` ก่อน
- embedding worker — ตาราง `embedding_jobs` กับ trigger พร้อมแล้ว เหลือเขียนตัวรันคิว
- อัปโหลดไฟล์รูปเล่มเข้า Storage
- หน้าให้นักเรียนส่งโครงงานเข้าคิว (ฝั่งฐานข้อมูลกับหน้าอนุมัติพร้อมแล้ว)
